# Slices: Magic Mirror

Build order, one capability per slice, each ending in a working + testable state. Provider order follows the spec (simplest → hardest).

**Proof split:** each slice lists `Prove (agent)` — binary conditions an automated task can verify (curl / unit tests / builds) — and `Prove (manual)` — live checks the operator runs by hand (browser rendering, real data on screen, network-kill, headless/kiosk boot). Only the agent-proofs are encoded as task acceptance criteria in `.agent/tasks/`.

- **Slice 1 — Tracer bullet (shell + contract):** Rust binary + Axum serves the ported static frontend (authored CSS, no Tailwind, self-hosted fonts) and `GET /api/v1/dashboard` returns a fully-hardcoded JSON matching the spec §5 shape. *Prove (agent):* curl `/`, `/api/v1/dashboard`, `/api/v1/health`; assets under `/assets/*` with correct content types; no CDN links in HTML. *Prove (manual):* browser renders clock (real local time) + all four sections at 1080×1920.
- **Slice 2 — Real weather + AQI:** replace the mock weather section with a live Open-Meteo forecast + air-quality fetch (config-driven lat/lon). Other sections still mock. *Prove (agent):* unit tests for WMO code mapping + unknown fallback; weather/AQI refresh independently configurable. *Prove (manual):* real temperature + EU AQI on screen.
- **Slice 3 — Real news:** replace mock news with RSS/Atom fetch + parse + dedup + per-feed isolation. *Prove (agent):* tests for dedup / missing-date / malformed; broken feed does not drop others. *Prove (manual):* real headlines render.
- **Slice 4 — Real transit:** replace mock transit with BKK FUTÁR arrivals-and-departures for configured stops (route/walking filters, realtime-vs-scheduled). *Prove (agent):* tests for filtering + `SCHEDULED` vs `ON TIME`; API key env-only. *Prove (manual):* real departure for a configured stop.
- **Slice 5 — Real calendar (hardest):** CalDAV discovery + bounded REPORT + iCalendar parse + recurring/DST expansion, using `happening/backend/src/caldav/` as reference. Replace mock events with real iCloud events. *Prove (agent):* recurring/DST expansion tests; read-only methods only; app password env-only. *Prove (manual):* real events render; a weekly recurring event with one overridden occurrence shows exactly once.
- **Slice 6 — Reliability:** stale/offline states, exponential backoff + jitter (honor Retry-After), last-good JSON persistence, restart recovery, security headers (CSP/nosniff/referrer), secret redaction. *Prove (agent):* simulated source failure → `STALE` + last-good retained; restart recovery; security headers via `curl -I`; no secrets in API JSON/logs. *Prove (manual):* kill network → data retained + marked `STALE`.
- **Slice 7 — Deployment + polish:** config validation hardening, systemd service, kiosk autostart, performance-budget check (RAM/binary/static size), real-device screenshot review + spacing. *Prove (agent):* config validation fails fast; systemd + kiosk files present; budgets reported. *Prove (manual):* boots headless, kiosk shows the mirror, real-device screenshot review.
